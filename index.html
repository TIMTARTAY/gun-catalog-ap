Move Data Between Devices

This GitHub Pages version cannot automatically synchronize records between devices without a secure cloud database and account system.

Use Export Full Backup, save the file in iCloud Drive, Google Drive, or another private location, then import it on your other phone or tablet.

Automatic Cloud Sync

Automatic live syncing requires a backend such as Supabase or Firebase. It is intentionally not enabled without your own private account and database credentials.

Privacy Lock

This is a local PIN screen. It prevents casual access but is not the same as native Face ID or full encryption.

About This Version

Version 4.0 includes inventory, multiple photos, accessories, maintenance history, safe map, wishlist, search, reports, local PIN lock, backups, dark mode, and offline support.

Cloud syncing and native Face ID require a secure backend or a native iPhone app. They are not included in this static GitHub Pages version.
